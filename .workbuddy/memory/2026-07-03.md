## navbar-nav 水平居中
- 现状：移除 brand 后 navbar-container 只剩 .navbar-nav + .navbar-actions，flex+space-between 导致 nav 靠左
- 目标：nav 真正水平居中（相对整个导航栏），actions 仍贴右
- 方案：绝对定位居中，无需改 HTML
  - `.navbar-container`：`justify-content` 从 `space-between` 改为 `flex-end`（nav 出流后，actions 单独贴右）
  - `.navbar-nav`：新增 `position:absolute; left:50%; top:50%; transform:translate(-50%,-50%); z-index:1`

- 不选 grid 三栏方案：需引入空占位列或调整放置，比绝对定位侵入性大
- 不选 flex `margin:0 auto`：在多 flex 子项场景下只能让 nav 在「左侧到 actions 之间」居中，非真正居中

## 修复窄屏 products 页悬浮滚动按钮覆盖侧边导航（z-index 层叠 BUG）
- 现象：≤768px 打开移动端侧边导航时，「向下滚动」悬浮按钮叠在导航之上
- 根因（层叠上下文陷阱）：
  - `.mobile-menu`（z-index:9999）是 `.navbar`（position:fixed + z-index:300，建立层叠上下文）的 DOM 子节点 → 被困在 navbar 的 300 级上下文内，9999 仅在 navbar 内部生效
  - 移动端 `.scroll-indicator`（@media max-width:768px 改为 position:fixed + z-index:1000）无 positioned 祖先 → 直接参与根层叠上下文
  - 根上下文：scroll-indicator(1000) > navbar(300) → 悬浮按钮盖住侧边导航
- 修复（双保险）：
  1. CSS：移动端 `.scroll-indicator` 的 `z-index:1000` → `var(--z-sticky)`(200)，低于 navbar 的 300，baseline 即让侧边导航盖住按钮
  2. CSS：新增 `body.mobile-menu-open .scroll-indicator { opacity:0; visibility:hidden; pointer-events:none }`，菜单展开时彻底隐藏并禁用点击（复用已有 opacity/visibility 过渡，平滑淡出）
  3. JS：`openMobileMenu`/`closeMobileMenu` 增删 `body.mobile-menu-open` 类（与 overflow:hidden 同生命周期，路由 beforeEach + 外部点击 + 关闭按钮均走 closeMobileMenu，覆盖所有关闭路径）
- 同步：dist/css/styles.css 直接 cp；`npm run build` 重建 js/bundle.min.js（nomodule 降级包），验证 bundle 含 mobile-menu-open、dist/css 含新规则
- 桌面端（>768px）不受影响：mobile-menu display:none 不开启；scroll-indicator 仍 position:absolute z-index:10
